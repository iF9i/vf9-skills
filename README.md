# vf9-skills

Claude Code plugins by [VF9](https://vf9.dev).

## Install

```bash
claude plugin marketplace add iF9i/vf9-skills
claude plugin install vf9-motion@vf9-skills
```

## Plugins

| Plugin | What it does |
|---|---|
| `vf9-motion` | Apple-style UI motion (hero-reveal, slide, pop-in, bounce-rotate, bump) as plain CSS + a tiny JS. RTL-ready, respects `prefers-reduced-motion`. |
